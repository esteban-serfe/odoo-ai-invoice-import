LLM Assistant

Assistants with their own model, tools and prompt, to use in the AI chat.

Your data goes to the AI provider you choose. Messages and documents are sent to the AI provider that you configure through your own LiteLLM proxy. This module does not send data to Serfe or to any fixed service.

What it does

  • Assistants: each with a provider, a model, tools and a prompt.
  • Prompts: templates built from role, goal, background, instructions and a footer, with categories and tags.
  • Prompt test wizard to try a prompt before using it.
  • Switch assistant from the chat header.
  • Preconfigured: Assistant Creator and Website Builder Assistant.

Who can use it

Users and managers have their own access rights; managers create and edit assistants and prompts. Serfe LLM Access Groups can restrict the menus.

What you need

An AI provider account and a LiteLLM proxy in front of it, both provided and operated by you. LiteLLM works with the API of each provider: follow the LiteLLM and provider documentation to set it up.
