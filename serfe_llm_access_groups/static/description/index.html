Access Groups for the LLM Modules

Decide who can configure the LLM features and who can chat with the AI.

What it does

  • Limits the LLM Configuration, Prompts and Training menus to LLM Manager. The base modules leave them open to every internal user.
  • Adds the User: LLM Chatter group, required to use the AI chat: the chatter “AI” button, the Chat menu and the chat threads.
  • Hides the chatter “AI” button from users outside that group.

Configuration

To let a user chat with the LLM, add them to User: LLM Chatter. LLM Manager includes it.

Good to know

  • Hiding the button is cosmetic; the real restriction is the access rule on the chat threads.
  • Groups are global, not per company.
