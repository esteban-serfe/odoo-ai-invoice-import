AI Chat in Odoo

Talk to a language model from the chatter of any record, or from its own chat.

Your data goes to the AI provider you choose. Messages and documents are sent to the AI provider that you configure through your own LiteLLM proxy. This module does not send data to Serfe or to any fixed service.

What it does

  • An “AI” button in the chatter of any record, to start a conversation linked to it.
  • A Chat menu with a sidebar of your threads and their history.
  • Choose the provider and model of each thread, among chat and multimodal models.
  • Choose the tools of each thread.
  • Streamed answers and an indicator while the model is working.

How to use it

  1. Configure a provider and fetch its models in LLM → Configuration.
  2. Press AI in a record’s chatter, or New Chat in the Chat menu.
  3. Pick a model, ask, and optionally enable tools.

Who can use it

By default every internal user can. LLM Access Groups restricts it to a dedicated group.

What you need

An AI provider account and a LiteLLM proxy in front of it, both provided and operated by you. LiteLLM works with the API of each provider: follow the LiteLLM and provider documentation to set it up.
