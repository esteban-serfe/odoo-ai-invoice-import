LLM Integration Base

Providers, models and publishers for working with language models in Odoo.

What it provides

  • Providers: records with the service type, API base URL and API key.
  • Models: with their use (chat, embedding, completion or multimodal), imported with the Fetch Models wizard.
  • Publishers: who makes each model, and whether it is official.
  • Security: the LLM Manager group edits providers, models and publishers. Internal users have read-only access.
  • Chat message types that the other LLM modules use for user, assistant, tool and system messages.

Providers

This module defines the provider framework. The only provider service implemented in this repository is LiteLLM (LiteLLM Proxy Integration), which reaches the other AI providers through your proxy. Other services need their own module.

Getting started

  1. Install the module and the LLM modules you need.
  2. Go to LLM → Configuration → Providers and create a provider.
  3. Press Fetch Models to import the available models.

What you need

An AI provider account and a LiteLLM proxy in front of it, both provided and operated by you. LiteLLM works with the API of each provider: follow the LiteLLM and provider documentation to set it up.
