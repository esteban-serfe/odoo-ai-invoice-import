LiteLLM Responses API for Odoo

Extends the LiteLLM provider with the Responses API, OCR through file inputs, and optional provider creation.

Your data goes to the AI provider you choose. The invoice document is sent to the AI provider that you configure through your own LiteLLM proxy. This module does not send data to Serfe or to any fixed service.

What it adds

  • Responses API: models whose model_info.mode is responses are routed through /responses, except when tools are present.
  • OCR through file inputs (input_file / input_image), retrying up to 3 times on transient invalid_file errors.
  • Cleaner chat: orphaned tool messages are removed before sending, and non-streaming chat_completion() returns the parsed result.
  • Model info: model listings are enriched with LiteLLM's /model/info and copied by the Fetch Models wizard.

Setting up the provider

  • Enter your proxy URL (API Base) and API Key in LLM → Configuration → Providers.
  • Optional: set LITELLM_API_BASE and LITELLM_API_KEY in the environment of the Odoo process before installing, and the LiteLLM provider is created for you. Without them the module installs normally.
  • Neither the URL nor the key has a default: they are yours.

What you need

Odoo 16 Community and an AI provider with a LiteLLM proxy in front of it, both provided and operated by you. LiteLLM works with the API of each provider: follow the LiteLLM and provider documentation to set it up.
