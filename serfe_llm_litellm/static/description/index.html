LiteLLM Proxy Integration

Reach many AI providers through a single LiteLLM proxy.

Your data goes to the AI provider you choose. Messages and documents are sent to the AI provider that you configure through your own LiteLLM proxy. This module does not send data to Serfe or to any fixed service.

What it does

  • Chat, streamed or not.
  • Tool calling: tools are sent to the model, and tool calls come back, including in streamed answers.
  • Embeddings.
  • Model discovery with Fetch Models, and a wizard to push models to the proxy.

Setting up

  1. Go to LLM → Configuration → Providers and create a provider with the service LiteLLM.
  2. Enter your proxy URL and API key.
  3. Press Fetch Models.

What you need

Your own LiteLLM proxy and AI provider account. This module only talks to the proxy: rate limits, costs and provider keys are managed in LiteLLM. Follow its documentation to set it up.
