LLM Tool

Tools that a language model can call to read and change Odoo data.

Tools included

  • Record retriever: search and read records.
  • Record creator, updater and unlinker: create, change and delete records.
  • Model inspector: look at the fields of a model.

Arbitrary method execution is disabled. Invoice extraction does not use chat tools.

How it works

  • Each tool declares its arguments with a schema generated from a Pydantic model, so the model knows how to call it.
  • A consent configuration lets you control how tools are used.
  • New tools are added by extending the tool model.

Be careful

Some tools can create, change or delete data. Review which tools you enable in each assistant or chat, and check what the model did.
