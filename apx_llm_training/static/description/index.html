LLM Training

Manage fine-tuning datasets and jobs from Odoo.

What it does

  • Datasets: create and manage training data.
  • Jobs: create a job with a provider, a base model, datasets and parameters, submit it and follow its status and metrics.

Providers

This module only defines datasets and jobs, and asks the provider to run them. No provider in this repository implements training, so you need a provider module that does.

Fork of an Apexive Solutions LLC module, maintained by Serfe. Questions about setup or adapting it to your case are welcome: contact Serfe.
